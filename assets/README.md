# Assets required before building

This directory needs the following binary assets added (not generated by this build,
since they are binary/design assets):

- `icon.png` — 1024x1024 app icon
- `splash.png` — splash screen image (dark green #1A3C34 background)
- `adaptive-icon.png` — Android adaptive icon foreground
- `fonts/NotoSansKannada-Regular.ttf` — download from Google Fonts (Noto Sans Kannada)
- `fonts/NotoSansKannada-Bold.ttf` — download from Google Fonts (Noto Sans Kannada)

Also place your Firebase Android config at the project root as `google-services.json`
(see README.md for how to obtain it from the Firebase console).

`App.js` will still run without the fonts present (it falls back to the system font),
but Kannada text should use Noto Sans Kannada in production for correct rendering.
